# Jarghaa Furniture website

A simple static website (no build step needed).

## Files
- `index.html`: the homepage
- `css/style.css`: all styling. Colours are at the top (`:root`).
- `images/`: put your photos here

## Preview locally
Double-click `index.html` to open it in your browser.

## Add your photos
1. Copy photos into `images/` (for example `images/beds.jpg`).
2. In `index.html`, replace each `[PHOTO]` with `<img src="images/beds.jpg" alt="Handmade wooden bed">`.
